

# Portfolio Website for Hamza Akram

## Overview
A modern, premium, single-page portfolio website showcasing your full-stack engineering expertise, real-world project contributions, and leadership experience. Clean design with smooth animations, strong typography, and a professional agency-style feel.

---

## Sections (in order)

### 1. Sticky Navigation Bar
- Logo/name on the left, section links on the right
- Smooth scroll to each section
- Mobile hamburger menu
- Subtle background blur on scroll

### 2. Hero Section
- Your name, title, and tagline front and center
- Two prominent CTA buttons: **View Projects** and **Contact Me**
- Clean, bold typography with a subtle gradient or accent color
- Optional animated background element for visual appeal

### 3. About Me
- Friendly professional bio highlighting your full-stack, AI, CMS, and cloud experience
- Clean layout with accent styling to break up the text

### 4. Services Grid
- 12 service cards in a responsive grid (agency-style)
- Each card with an icon, title, and short description
- Covering: Full-Stack, React Frontend, Backend, Auth & SSO, Billing, Agentic AI, AI Avatars, Accessibility, CMS, AWS, Vibecode Fixer, Team Leadership
- Hover effects for interactivity

### 5. Featured Projects
- 5 project cards as the main highlight section
- Each card shows: Project Name, Type badge, Contribution details, Key Outcome, and Tech/Tools
- Modern card design with clean typography — no real company names used

### 6. Skills & Tech Stack
- Categorized badge groups: Frontend, Backend, Cloud & DevOps, CMS, Billing, AI, Accessibility
- Visual, scannable layout

### 7. Work Process
- 4-step horizontal or vertical timeline: Understand → Design → Build → Deploy
- Clean icons and descriptions for each step

### 8. Leadership & Key Achievements
- Bullet-point highlights of career achievements (team leadership, billing integrations, accessibility, PHP learning, debugging)

### 9. Contact Section
- Email, LinkedIn, and GitHub placeholders with icons
- Tagline: "Want to build something impactful? Let's connect."
- Simple contact form or direct links

---

## Design & UX
- **Color scheme**: Dark primary with accent color for a premium feel
- **Typography**: Strong, modern font hierarchy
- **Animations**: Fade-in on scroll, hover effects on cards and buttons
- **Fully responsive**: Desktop, tablet, and mobile
- **No backend needed** — purely static content

# Hamza Akram — Portfolio Web

Portfolio site for **Hamza Akram**, Senior Software Engineer. Showcases scalable web products, system integrations, and projects from SaaS platforms to AI-powered experiences.

## Tech stack

- **Vite**
- **TypeScript**
- **React**
- **React Router**
- **shadcn/ui**
- **Tailwind CSS**
- **Framer Motion**

## Getting started

Requirements: Node.js and npm ([install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)).

```sh
# Clone the repository
git clone https://github.com/hkakram97/portfolio.git

# Go to the project directory
cd portfolio

# Install dependencies
npm i

# Start the dev server
npm run dev
```

## Scripts

| Command        | Description              |
